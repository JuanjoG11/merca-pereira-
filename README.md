# Mercado Pereira Resiliente 🛍️🇨🇴

**Marketplace local de reactivación económica para Pereira tras el sismo del 10 de Agosto de 2026.**

Conecta a emprendedores, comerciantes e independientes con compradores de toda la ciudad. Publicación de productos con foto, precio y contacto directo por WhatsApp. Base de datos en tiempo real con Supabase.

---

## Funcionalidades

- 🛒 Catálogo visual con fotos de productos/servicios
- 💬 Contacto directo al vendedor por WhatsApp con mensaje pre-llenado
- 📍 Filtros por barrio/sector de Pereira (Cuba, Centro, Circunvalar, Dosquebradas, etc.)
- 📂 Filtros por categoría (Víveres, Construcción, Servicios, Restaurantes, Tecnología, Hogar)
- ☁️ Supabase: Base de datos en la nube + Storage de fotos + Realtime en vivo
- 📱 Diseño mobile-first adaptable a cualquier dispositivo
- ⚡ Skeleton loader y actualizaciones en tiempo real sin recargar

---

## Tecnologías

- HTML + CSS + JavaScript Vanilla
- [Supabase](https://supabase.com) (PostgreSQL + Storage + Realtime)
- Font Awesome 6 + Google Fonts (Outfit, Inter)

---

## Configuración inicial (Supabase)

1. Ve a tu proyecto en [Supabase SQL Editor](https://supabase.com/dashboard/project/wqqwmtfupeejqzfnujdm/sql/new)
2. Ejecuta el archivo `setup.sql` incluido en el repositorio
3. Abre `index.html` en un servidor local o despliega en Netlify/Vercel/GitHub Pages

---

## Despliegue rápido

### Opción 1 – GitHub Pages
Activa GitHub Pages desde la rama `main` en los Settings del repositorio.

### Opción 2 – Netlify (recomendado)
1. Ve a [netlify.com](https://netlify.com)
2. "Add new site" → "Import from GitHub"
3. Selecciona este repositorio → Deploy
